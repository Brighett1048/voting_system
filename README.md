# voting_system

## Overview
A structured digital voting application designed to manage voter registration, securely cast ballots, and calculate election results in real-time. This project highlights robust backend logic, data validation, and object-oriented programming (OOP) principles to ensure a reliable and accurate voting process.

## Key Features
* **User Authentication:** Secure registration and login flows for voters and system administrators.
* **Ballot Integrity:** Prevention of duplicate voting by checking voter status attributes before committing votes.
* **Real-Time Tallying:** Automated background counting mechanics that dynamically aggregate election results.
